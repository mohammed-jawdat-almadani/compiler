# دليل تشغيل مشروع المترجمات (المرحلة الثانية)

هذا الملف يوضح هيكلية المشروع الخاص بمادة المترجمات وكيفية تشغيله.
يقوم المترجم (المكتوب بلغة Java باستخدام ANTLR4) بقراءة مشروع ويب مصغر يعتمد على Python وقوالب Jinja2، وتحليله دلالياً ونحوياً لتوليد صفحات HTML نهائية.

## بنية المشروع

- `Compiler_1/`: يحتوي على الكود المصدري للمترجم (قواعد ANTLR، شجرة AST، التحليل الدلالي، ومولد الكود).
- `PROJECT1/`: يحتوي على كود المشروع الهدف المراد ترجمته (توجيهات Flask، بيانات، وقوالب Jinja).
- `output/`: مجلد يتم إنشاؤه تلقائياً ليحتوي على صفحات HTML النهائية بعد عملية التوليد.
- `compiler_output/`: يحتوي على تقارير المترجم (سجل الأخطاء الدلالية، والشجرة المجردة AST).

## متطلبات التشغيل الأساسية
- توفر بيئة Java JDK (إصدار 11 أو أحدث) لتشغيل المترجم.
- مكتبة ANTLR (مرفقة مسبقاً داخل مجلد `Compiler_1\dependencies`).
- بيئة Python 3 (لتشغيل المشروع الأساسي كخادم ويب قياسي).

## خطوات التشغيل (من موجه الأوامر)

يرجى فتح موجه الأوامر (Terminal أو PowerShell) في المجلد الرئيسي `compiler`، وتنفيذ الخطوات التالية بالترتيب:

### أولاً: تشغيل المشروع الأساسي مباشرة (اختياري)
في حال أردت اختبار وتجربة المشروع المصدر `PROJECT1` بشكل طبيعي باستخدام إطار عمل Flask قبل إدخاله في المترجم:
```powershell
cd PROJECT1
pip install flask
python app.py
```
ثم افتح متصفحك على الرابط `http://localhost:5000/`. (بعد الانتهاء، اضغط Ctrl+C لإغلاق الخادم وعد للمجلد الرئيسي `cd ..`).

### ثانياً: تجميع كود المترجم (Compilation)
يجب تجميع ملفات المصدر (`.java`) الخاصة بالمترجم أولاً وحفظها في مجلد مخصص.
```powershell
mkdir Compiler_1\out
javac -Xlint:none -cp "Compiler_1\dependencies\antlr-4.13.2-complete.jar" -d "Compiler_1\out" @(Get-ChildItem -Path "Compiler_1\src" -Recurse -Filter *.java).FullName
```
ملاحظة: إذا كنت تستخدم IDE مثل IntelliJ أو Eclipse، يمكنك إعداد المشروع لربط الـ JAR وعمل Build بشكل مباشر.

### ثالثاً: الترجمة وتوليد الموقع الثابت
لترجمة المشروع `PROJECT1` وإنشاء صفحات الويب الثابتة في المجلد `output`:
```powershell
java -cp "Compiler_1\dependencies\antlr-4.13.2-complete.jar;Compiler_1\out" Main PROJECT1 .
```

### رابعاً: تشغيل المترجم كخادم تطوير (الوضع التفاعلي)
يتيح هذا الوضع فتح الموقع المترجم في المتصفح، حيث يستمع لعمليات الإضافة والحذف عبر الواجهة ويقوم بتقييم الكود وتحديث الـ HTML ديناميكياً:
```powershell
java -cp "Compiler_1\dependencies\antlr-4.13.2-complete.jar;Compiler_1\out" DevServer PROJECT1 . 8000
```
بعد تشغيل الأمر، افتح متصفحك وانتقل إلى الرابط: `http://localhost:8000/`

## المخرجات والتقارير
بعد نجاح ترجمة المشروع، يرجى التوجه إلى مجلد `compiler_output/` ومراجعة ملف `semantic_report.txt` للتأكد من خلو كود البايثون والقوالب من أي أخطاء دلالية.
